# 🚀 Showcase Quickstart Guide: realtime-driver-drowsiness-ai

Follow these simple 1-step instructions to install all dependencies and launch the interactive web dashboard!

---

## ⚡ Option 1: 1-Click Automated Setup (Recommended)

### Windows Users:
Double-click `setup_environment.bat` or run:
```cmd
setup_environment.bat
```

### Linux / macOS Users:
Run:
```bash
chmod +x setup_environment.sh
./setup_environment.sh
```

---

## 🛠️ Option 2: Manual Terminal Commands

1. **Install Dependencies**:
```bash
pip install -r requirements.txt
pip install gradio
```

2. **Launch Interactive Web Dashboard**:
```bash
python dashboard.py
```

3. **Open Browser**:
Navigate to `http://localhost:7860` in your web browser to view and showcase the live interactive system!
